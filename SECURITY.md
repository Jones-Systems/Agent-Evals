# Security Policy

## Supported versions

Agent-Evals is alpha software. Security fixes are made on the latest `main`
revision; no released compatibility branches are currently supported.

## Reporting a vulnerability

Use **Report a vulnerability** on this repository's GitHub Security page to
send a private report. Include affected versions or commits, impact, and the
smallest safe reproduction you can provide.

Do not open a public issue for an undisclosed vulnerability, and do not include
credentials, private evaluation data, or other sensitive material in a report.
You should receive an acknowledgement within seven days. Coordinated disclosure
timing will be discussed after the report is reproduced and assessed.

Public hardening suggestions that do not reveal an exploitable vulnerability
may use an ordinary issue.
